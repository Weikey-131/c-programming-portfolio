// Debugging
One important bug I fixed was a transaction validation problem in the BroBank project.

This issue occurs because a failed transaction can modify the account balance before all validation checks are completed. I discovered this problem by testing invalid withdrawals and checking whether the balance changed after the operation failed. My fix involves moving the validation checks to occur before the balance update, thereby ensuring that unsuccessful transactions do not alter the system state.
